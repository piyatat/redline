# Android demo moved

The Android sample app lives under the Gradle project:

**`android/AndroidDemo`**

Open **`redline/android`** in Android Studio (the folder that contains `settings.gradle.kts`), then run the **AndroidDemo** configuration.

```bash
./scripts/run-android-demo.sh
```

See [docs/android-setup.md](../docs/android-setup.md) · host apps: [docs/integration.md](../docs/integration.md).
